# 为什么 F:\COMFYUI 里看不到？

云端助手**写不进你电脑的 F 盘**。  
文件在 GitHub 仓库目录：`comfyui-治愈系视频/`，需要你**手动下载后拷贝**到本机。

## 30 秒拷贝法

1. 打开 PR / 仓库里的 `comfyui-治愈系视频` 文件夹  
2. 点 Code → Download ZIP，或单独下载 `workflows` 里的 json  
3. 在本机新建目录（推荐）：

```text
F:\COMFYUI\user\default\workflows\治愈系视频\
```

或：

```text
F:\COMFYUI\入门工作流\治愈系视频\
```

4. 把所有 `.json` 丢进去  
5. 打开 ComfyUI → 把 json **拖进画布**，或「工作流 → 打开」

## 你已经下了 MiniMax H3？优先用这 3 个

| 文件 | 用途 |
|------|------|
| `05_治愈系_文生视频_MiniMax_H3.json` | 文字 → 视频+原生音频（最推荐） |
| `06_治愈系_图生视频_MiniMax_H3.json` | 静帧 → 视频+音频 |
| `07_治愈系_参考生视频_MiniMax_H3.json` | 参考图锁风格/人物（需 ref2va） |

Wan2.2 的 `01–04` 是备选；**有 H3 就别优先用 Wan**，H3 画质与带声音效更强。

## ComfyUI 里也能直接开官方模板

菜单：**工作流 → 浏览模板 → 视频 → MiniMax H3 T2V / I2V / R2V**  
然后把提示词换成 `prompts/治愈系提示词库.md` 里的内容即可。

# 章名规范（《我的技能全是满级》）

日更写章前必读。与 `story-long-write` 的 `outline-methods.md`「章节名策略」对齐，本书额外加硬约束。

## 原则

1. **禁止干瘪物件标签**：不用「墙里」「铅袋」「换线」这类两字工单式标题。
2. **优先金句/冲突**：从本章最有梗的一句对话、最悬的一个动作、或带地标的场景取名（例：`换线了`、`周衡截停`、`B-7检修口`）。
3. **铺垫章也要有噱头**：信息章不能叫「入口」「支管」，须加地点或事件（例：`西向支管`、`五号暗仓`）。
4. **避免「线」字连发**：相邻三章内，标题不得出现两个以上以「线」结尾或为核心词的章名（管网术语可进正文，不进章名堆叠）。
5. **字数**：宜 3–8 字；对话体可更长（如 `修水电的也配`）；单字标题禁用。

## 日更自检（落盘前）

- [ ] 与相邻章标题不重复（轻量去重）
- [ ] 不是纯物件/纯术语两字标签
- [ ] 读者不看正文也能感到「有事要发生」
- [ ] 细纲 `### 第 N 章：`、正文 `# 第N章`、文件名 `第NNN章_标题.md` 三者一致

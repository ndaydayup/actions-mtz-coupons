# 章名规范（《我的技能全是满级》）

日更写章前必读。与 `story-long-write` 的 `outline-methods.md`「章节名策略」对齐，本书额外加硬约束。

## 网文章名怎么起（对标参考）

拆文库同类书常见取法：

| 类型 | 对标示例 | 本书好用示例 |
|------|----------|--------------|
| 地标/场景 | 王剑、降神盘 | 十二楼、旧水厂、电表箱、弱电井 |
| 人物+动作 | 幼女魔法使 | 周衡截停、有人找上门 |
| 对话/威胁句 | 停止调查 | 别出门、欠你的、市一院见 |
| 物件+异象 | 【呼吸】 | 铅盒在搏动、墙里呼吸 |
| 身份/能力点 | 技能活化 | 满级、废物系、巧劲再升 |

**少用**：结果汇报（回声全灭）、叫醒口令（林牧醒醒）、病情播报（疗程没断）、管网工单词（断线/换线/病线）。

## 原则

1. **像章节，不像日志**：标题是诱饵，不是本章 KPI 总结。
2. **优先三类**：地标场景 / 对话威胁 / 物件异象；铺垫章也要让读者想点进去。
3. **标题禁用「线」**：章名不写断线、换线、病线等管网术语（正文、追踪可用）。
4. **禁直呼主角全名**：不用「林牧醒醒」这类元叙事口令。
5. **字数**：宜 3–8 字；对话体可更长（如 `修水电的也配`）；单字标题禁用。
6. **相邻三章**：标题类型宜有变化（地点→威胁→地点），避免语义同类连发。

## 日更自检（落盘前）

- [ ] 与相邻章标题不重复（轻量去重）
- [ ] 不是结果汇报、不是叫醒/状态播报
- [ ] 不是纯两字工单标签
- [ ] 读者不看正文也能感到「有事要发生」
- [ ] 细纲 `### 第 N 章：`、正文 `# 第N章`、文件名 `第NNN章_标题.md` 三者一致

# 卷纲 · 第一卷：废物维修工（约30万字 / ~80章）

## 卷功能
铺垫起步 + 第一个大爽点循环。把"被判废物系 → 满级活化 → 打脸天骄"的核心爽点跑通，立住人设与金手指，结尾把主角推进觉醒者圈子。

## 起始 → 结束状态
被欺压的穷维修工（无品阶、母病缺钱）→ 崭露头角的"生活系黑马"（拿到第一笔超凡报酬、被高人注意、活化2-3个技能）。

## 对标结构坐标（_面板流黄金三章公式 + outline-structure-theory）
- 黄金三章（1/40 处）：觉醒面板 + 评级被嘲 + 首次打脸（EM-001 面板首秀 / EM-003 逆天天赋+门槛）
- 1/4 处（~20章）：第一次靠"活化组合"接异化体委托赚到药费首款（EM-002 机制爽点引擎兑现）
- 中点（~40章）：被卷入一场更大的异化事件，废物系当众扬名，王浩彻底沦为背景板
- 3/4 处（~60章）：评级官/某家族打压升级，林牧用满级活化反杀，拿到入觉醒大学/团队的资格
- 卷尾（~80章）：解锁第一个"技能组合"高阶活化；神秘强者现身收徒/留线，引出"源"的第一个悬念

## 爽点节奏（情绪弧线，含章节定位）
| 段 | 章节定位 | 情绪 | 爽点形态 |
|---|---|---|---|
| 1-3 | 高压/推进 | 压抑→反差爽 | 觉醒+首次打脸 |
| 4-10 | 推进+低压交替 | 期待+市井温情 | 活化练手、接小委托、母女线 |
| 11-20 | 高压 | 爽感释放 | 接异化体委托赚药费、打脸势利眼 |
| 21-40 | 推进+高潮 | 燃 | 中点大事件扬名 |
| 41-60 | 高压+关系 | 爽+情感 | 打压反杀、入学资格 |
| 61-80 | 高潮+信息 | 燃+悬念 | 组合活化解锁、强者留线 |

## 人物弧线
- 林牧：自卑隐忍 → 用实力立规矩，开始敢要、敢争（学《活化技能》"人死债消式"性格授权——这里是"被逼到绝境+面板给底气"）
- 王浩：嚣张天骄 → 第3章被打脸 → 中点彻底沦为背景，立"打脸样板"
- 母亲/妹妹：动机锚点，药费线推动主角每一步算计

## 伏笔（埋设/回收）
- 埋：①面板"高阶活化/组合已锁定"（卷尾解锁）②妹妹或有资质 ③母亲旧疾与灵潮的关系 ④神秘强者身份 ⑤"源/涨潮"周期
- 回收（本卷内）：评级不公→反杀；首次活化耗点焦虑→赚到熟练点来源

## 反转
- 反转1（第3章）：人人以为废物系无用 → 市井技能活化吊打战斗系（身份/价值反转）
- 反转2（中点）：以为只是小异化事件 → 牵出更大隐患，废物系成关键

## 大纲五检（本卷）
1. 交付情绪：反差爽感（废物吊打天骄）+ 市井代入温情。模式：打脸逆袭循环。
2. 核心冲突：废物系 vs 主流偏见 / 穷困 vs 药费 / 异化威胁。
3. 节奏：黄金三章加速，4-10章张弛交替喘息，11章起重新加速。
4. 伏笔：见上；卷尾解锁组合活化。
5. 章节定位有高低层次：高压章（1-3/11-20）与低压关系章（4-10含母女线）交替，低压不超15%。1/4·中点·3/4 各锚一个关键情节。
